# โครงการ Doi Tung Website 🏔️

เว็บไซต์สำหรับนำเสนอผลิตภัณฑ์พรีเมียมจากดอยตุง (Doi Tung) ไม่ว่าจะเป็นกาแฟ แมคคาเดเมีย และงานหัตถศิลป์ พร้อมทั้งบอกเล่าเรื่องราวความภูมิใจและพันธกิจเพื่อความยั่งยืนของชุมชน

## 🔗 ลิงก์เข้าชมเว็บไซต์ (Live Demo)
สามารถเข้าชมเว็บไซต์ตัวอย่างได้ที่: [https://doi-tung.vercel.app/](https://doi-tung.vercel.app/)

---

## ✨ คุณสมบัติเด่น (Features)
- **ระบบหลายภาษา (Bilingual Support):** รองรับทั้งภาษาไทยและภาษาอังกฤษ (Thai & English).
- **ดีไซน์ทันสมัย (Modern Design):** ออกแบบด้วยความเรียบหรู เน้นรูปภาพที่สวยงามและใช้งานง่าย.
- **การแสดงผลที่ตอบสนอง (Responsive Design):** รองรับการใช้งานทั้งบนคอมพิวเตอร์ แท็บเล็ต และมือถือ.
- **ระบบค้นหาและกรองสินค้า (Search & Filter):** ค้นหาสินค้าที่ต้องการได้ตามหมวดหมู่และชื่อสินค้า.
- **รายละเอียดสินค้าขั้นสูง (Product Details):** มีหน้ารายละเอียดสินค้าแยกเฉพาะพร้อมข้อมูลที่ครบถ้วน.
- **แอนิเมชันลื่นไหล (Smooth Animations):** ใช้ Scroll Reveal เพื่อเพิ่มความน่าสนใจให้กับเนื้อหา.

---

## 🛠️ เทคโนโลยีที่ใช้ (Technologies Used)
- **HTML5:** โครงสร้างเว็บมาตรฐานและ Semantic HTML.
- **CSS3:** จัดรูปแบบด้วย Vanilla CSS, CSS Variables และ Flexbox/Grid.
- **JavaScript (Vanilla JS):** จัดการตรรกะเบื้องหน้า (Frontend Logic) และการดึงข้อมูลสินค้า.
- **i18n Translation:** ระบบแปลภาษาที่ปรับเปลี่ยนได้ทันที.
- **Vercel:** สำหรับการ Deploy และ Host เว็บไซต์.

## 📁 โครงสร้างไฟล์ (Project Structure)
- `index.html`: หน้าหลัก (Home Page)
- `products.html`: หน้าแสดงรายการสินค้าทั้งหมด
- `product-detail.html`: หน้าแสดงรายละเอียดสินค้าเชิงลึก
- `contact.html`: หน้าติดต่อสอบถาม
- `styles.css`: ไฟล์สไตล์สำหรับทั้งโปรเจกต์
- `scripts.js`: ไฟล์จัดการระบบแปลภาษา การค้นหา และการแสดงผลไดนามิก
- `/data`: ไฟล์ JSON สำหรับเก็บข้อมูลสินค้า
- `/lang`: ไฟล์ JSON สำหรับเก็บคำแปลภาษาต่างๆ
- `/images`: โฟลเดอร์เก็บรูปภาพประกอบทั้งหมด
